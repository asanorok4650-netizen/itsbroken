# RBXL Player — Home UI v0.2

iPadのローカルファイルプレビューで動作しやすいよう、ES Modulesを使わない通常のscript読み込みに変更しました。

## 起動
ZIPを展開して `index.html` をブラウザで開きます。ボタンでファイル選択画面が開き、`.rbxl` / `.rbxlx` のファイル名とサイズを最近のゲームに登録します。

## 実装済み
- サイドバーのページ切り替え
- モバイル用メニュー
- ファイル選択UI
- ファイル名・サイズのlocalStorage保存
- ゲーム名検索

## 注意
iOSのファイルプレビューアプリやブラウザによっては、ローカルHTMLのJavaScript実行やファイル選択に独自の制限があります。その場合はHTTPSの静的ホスティングで開いてください。
このバージョンでもRBXLの解析・3D描画・スクリプト実行・マルチプレイは未実装です。
